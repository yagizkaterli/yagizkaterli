## Reliability and evaluation

**Proof of Delivery** is an ongoing research manuscript on separating an agent's completion claim from execution receipts, artifacts, independent checks, and durable evidence. It is **research in progress**, not a peer-reviewed publication.

[HERAKLES Eval Lab](https://github.com/yagizkaterli/herakles-eval-lab) focuses on false progress and evidence-based assessment. [Zhengwei](https://github.com/yagizkaterli/heraklesharness) anchors review findings to changed diff lines and explicitly distinguishes deterministic findings from semantic approval.
